# 오프라인으로 학습한 직접 선택기가 Godunov보다 빠를 수 있는가?

동결된 2→16→16→1 FP64 flux MLP, 128셀 주기 Burgers, 60스텝, CPU 1스레드에서 스텝별로 신경망을 쓸 면을 결정했다. 기존 확인 세트 9개(시드 241124)의 동일한 초기조건과 동일한 오차 예산을 사용했다. 오차 보장은 동일 격자의 정확 산술 Godunov 궤적에 대한 공간 평균 절대 오차에 적용된다.

## 실제 학습형 라우터

1. 훈련용 초기조건 12개(시드 1100)로 Godunov를 실행하고, 입력 상태 쌍이 속한 구간별로 신경망의 **부호 있는 평균 flux 오차**와 평균 절대 오차를 추정했다. 구간을 경험적 위험도에 따라 16단계로 나눴다.
2. 1차 표로 생성한 궤적을 다시 관찰했다. 실제 부호 있는 오차를 크게 잘못 예상한 표본에는 5배 가중치를 주어 표를 갱신했다. BAMG의 피드백 원리를 차용했고 flux 신경망의 가중치는 고정했다.
3. 온라인에서는 현재 면들의 입력 구간과 남은 오차 예산으로 16개 임계값 중 하나를 선택한다. 두 이웃 면의 오차 차이에 대한 추정 합으로 후보를 평가하고, 안전 여유로 스텝 허용량의 절반을 사용한다. 학습 중 보지 못한 입력 구간에는 Godunov를 제안한다. 루프는 격자 크기에 선형이며 후보 조합을 탐색하는 기존 동적 계획법을 생략한다.
4. 제안한 마스크 하나만 오프라인 중심점 표로 인증한다. 허용량을 넘으면 그 스텝 전체에서 Godunov를 사용한다. 점별 Godunov 조회와 온라인 구간 미분은 검증에 사용하지 않는다. 신뢰 여부와 관계없이 업데이트 연산의 반올림 예산을 반영한다.

| 방법 | 인증된 신경망 면 비율 | 60스텝 전체 시간 |
|---|---:|---:|
| 기존 순수 Godunov | 0% | 2.16 ms |
| 기존 중심점 표 + 동적 계획법 | 55.33% | 259.80 ms |
| 1차 학습 직접 선택기 | 18.82% | 34.42 ms |
| 2차 학습 직접 선택기 | 19.30% | 34.28 ms |

시간은 각 초기조건에서 전체 60스텝 워밍업 후 5회 측정한 중앙값을 9개 조건에 대해 평균한 것이다. 순서를 섞었고 사후 정답 검산은 타이머 밖에서 수행했다. 재학습의 채택률 차이는 0.48%p이며, 1차와 2차의 작은 시간 차이로 시간 개선을 주장하기는 어렵다. 2차 선택기는 총 540스텝 중 286스텝에서 제안한 마스크가 인증 허용량을 넘어서 전체 Godunov로 돌아갔다. 모든 확인 사례에서 최종 예산을 지켰다. 별도 재실행한 540스텝에서 유리수 한 스텝 오차와 누적 오차 감사를 통과했다. 누적 검산에는 기준 FP Godunov 궤적의 반올림 여유를 포함했다.

입력 표 준비 시간은 기본 인증 표 1.20초, 중심점 표 0.74초다. 훈련용 예산 보정에는 10.47초, 실제 두 학습 라운드에는 0.81초가 들었다. 학습·보정·준비는 온라인 시간에서 제외했다. 두 라운드의 표 및 모델 지문은 함께 저장하였다.

## 선택 비용을 0으로 놓은 대조군

미리 정한 면에 대해 신경망 FP64 계산과 나머지 면의 Godunov 계산 및 업데이트만 수행했다. NumPy 고정 마스크 비교에서는 시점에 따라 위치가 바뀌는 연속된 구간을 미리 만들어 두었다. 오차 예산 검사는 이 대조군의 목적에서 제외된다.

| 경로 | 60스텝 시간 |
|---|---:|
| 저장소의 순수 NumPy Godunov | 2.23 ms |
| 같은 업데이트에서 간단한 닫힌식으로 쓴 NumPy Godunov | 1.00 ms |
| 스텝당 1개 면만 MLP, 나머지 Godunov | 6.94 ms |
| 스텝당 70개 면 MLP, 나머지 Godunov | 9.85 ms |
| 스텝당 전체 면 MLP | 9.41 ms |

실제 2차 게이트의 9개 궤적에서 매 스텝 채택 마스크와 인덱스를 미리 저장해 동일 궤적을 재생했다. 선택·인증·예산 회계를 전부 제거했을 때 5.403 ms, 같은 업데이트의 전체 Godunov는 2.083 ms, 공개 Godunov 솔버는 2.169 ms였다. 9회 반복 모두 최종 상태가 실제 인증 경로와 비트 단위로 일치했다. 이 대조군은 실제 정책 경로의 비용을 분해하는 진단이며, 사전에 모르는 초기 상태에서 인증을 대신할 수는 없다.

GCC로 같은 조건의 FP64 커널을 컴파일한 추가 대조군에서는 9개 초기조건의 60스텝 시간이 전체 Godunov 11.04 µs, 사전 지정한 절반의 면에 신경망 사용 259.96 µs, 전체 신경망 533.11 µs였다. 각 경로의 1·8·60스텝 결과가 대응하는 NumPy 결과와 비트 단위로 일치했다. 컴파일된 대조군은 검증기 자체의 시간이나 서로 다른 하드웨어 간 성능을 측정하지 않는다.

현재 MLP는 면마다 가중치 곱 304번과 32개 은닉 ReLU를 계산한다. Burgers의 Godunov flux는 양쪽 상태의 부호를 포함한 최댓값을 구한 뒤 제곱하면 된다. 시간 절약이 가능하려면 실제로 줄인 Godunov 계산 시간이 채택한 신경망 계산, 분할·병합, 검증의 비용을 넘어야 한다. 면을 일부만 계산하는 배치의 시간은 면 수에 비례하지 않을 수 있다.
